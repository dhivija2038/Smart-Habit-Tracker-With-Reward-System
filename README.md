# Smart Habit Tracker with Reward System 🌟

**Smart Habit Tracker with Reward System** is a Python-based application designed to help users build and maintain positive daily habits. The platform encourages consistency by tracking habit completion, assigning reward points, and providing motivational feedback based on user performance.

The project creates an interactive habit-building experience where users can monitor their progress and stay motivated toward achieving their personal goals.

### Features

* Add and manage multiple daily habits
* Track habit completion status
* Reward system with points for completed habits
* Penalty system for missed habits
* Daily progress updates and feedback
* Level-up achievement system
* Final performance summary report
* Motivational messages for users

### Technologies Used

* Python 3
* Loops and Conditional Statements
* Lists
* User Input Handling
* Functions and Basic Logic Implementation

### Objective

The main objective of Smart Habit Tracker with Reward System is to help users develop discipline and consistency by encouraging positive habits through a reward-based tracking system.

### Future Enhancements

* Add graphical user interface (GUI)
* Store habit data using a database
* Add reminders and notifications
* Include progress charts and analytics
* Add user authentication and profiles
